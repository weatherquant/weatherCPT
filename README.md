# weatherCPT
Prospect-Theory Decision Thresholds for Low‑Probability, High-Impact Weather Risks: A Behavioral Extension of the Cost-Loss Model

Operational decisions for rare, high‑impact hazards are often guided by the classical cost–loss rule, which prescribes action when forecast probability exceeds C/L. We embed Cumulative Prospect Theory (CPT) into the cost–loss framework and show that the classical linear threshold fails in the rare‑event regime. CPT yields nonlinear triggers that depend on loss‑side curvature (β) and probability weighting (δ); small changes in δ at very low probabilities produce large shifts in trigger behavior. We extend the model to imperfect protection via a residual‑loss term Lr/L, demonstrating that partial effectiveness raises thresholds and magnifies behavioral heterogeneity. We also define a CPT‑consistent economic value metric and evaluate performance using stylized experiments. In a representative rare‑events setting (C/L=0.05, β=0.88, δ=0.50), a CPT‑aligned trigger attains markedly higher economic value than the classical rule, indicating that earlier, probability‑overweighted action can outperform "wait‑for‑C/L" strategies. Results reconcile behavioral realism with operational value and motivate behaviorally informed thresholds and risk communication for warnings, evacuations, and precautionary closures—especially where protective measures are imperfect. This prospect‑theoretic extension maintains the simplicity of a single trigger while capturing empirically observed deviations from expected‑utility decision making, offering a practical pathway for forecasters and emergency managers to align forecast use with real‑world behavior.
